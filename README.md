## 🚀 Featured Project

### [PhishAlert — AI-Based Phishing Detection System](https://github.com/fideinyama/phishalert)
> 🏆 1st Place — AI Unleashed Hackathon, Northumbria University 2025

A real-time, multi-agent AI system that detects phishing emails, explains threats in plain English, and guides users to act — without needing a security team.

- **Agent 1:** BERT-based email classification and threat scoring
- **Agent 2:** Deep enrichment — link scanning, IP geolocation, attachment analysis, SPF/DKIM validation
- **Agent 3:** LLM-generated plain-English summaries with SHAP explainability
- Built with Python, Next.js, Google Cloud | GDPR-compliant by design
- 🌐 Live at [phishalert.azronix.xyz](https://phishalert.azronix.xyz)
